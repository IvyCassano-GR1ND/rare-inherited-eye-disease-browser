临床资料管理

每行一条文献记录，按 ORPHA 编号关联疾病。相同记录编号更新原记录，新编号追加记录。导入仅保存在当前浏览器，不会自动更新公开网站。

Excel 填写后选择“CSV UTF-8（逗号分隔）”保存。文献链接填写 https:// 开头的完整地址。导出网页后重新部署，其他人才会看到更新。

填写与上传步骤
  1. 选择具体疾病，下载模板（自动带上疾病编号）；或下载空模板一次填写多个疾病。
  2. 一篇文献对应一行。记录编号自己命名，例如 ORPHA65-001；以后修改该行时保留编号。
  3. 填写症状体征、辅助检查及参考文献；同一格可用分号分隔多个表现，未报告的项目可留空。
  4. 选择 CSV 文件，查看预览及错误信息，再点击“确认导入”。搜索框选择“症状／辅助检查”验证结果。
  5. 先导出 CSV 留作备份。更新网站可直接导出 index.html 并上传；使用 GitHub 自动构建时，将 CSV 改名 clinical.csv 上传到仓库 data 文件夹。

资料应为文献整理的疾病信息。病例表现不等同于所有患者的典型表现；检索为关键词匹配，不输出诊断概率。
